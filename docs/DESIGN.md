# Vietnam standalone design

The accepted combined 1.1.0 source stays preserved. This project has owner
`813ebcc2-7f31-4db9-aa58-63aeba21c2cc`, native race/bundle/audio key `vietnam` and its own additive
Extension archive. Exactly one root, one flat RaceBP, owned native info metadata
and hash-bound dispatcher register the civilization beside stock choices.
Native Standard owns starting armies and victory. There is no copied combined
chooser, opening match hold, race conversion, game-mode replacement or global HUD
XAML override.

## Preserved start and mechanics

Start: 150 food, 200 wood, 100 gold, 0 stone; six villagers, a scout and one Buffalo. The initializer validates the direct native army and does not
spawn or charge it a second time. Hooks enroll only a living eligible human of
the exact owned race. No-own-player matches do not start custom HUD/audio loops.
Korea keeps its 100,000 Literature storage and native action cap of two.

Imported gameplay numeric/Boolean leaves are preserved; owner-qualified and
typed race membership references are translated. Stock voice/speaker codes are
copied from the actual donor used in accepted 1.1.0. Current custom native
art/audio member bytes remain unchanged. No modeling or balance redesign is part
of this split. Korean models remain the current stock visuals.

Vietnam retains its destination-click tunnel cooldown, buffalo work/leave,
paddies, defensive systems, landmarks and scripted voices. Its count/cycle HUD
uses a uniquely named local SCAR presenter instead of replacing the global HUD.
The Citadel's existing mover admission names retain optional Persian/Korean
independent names without requiring those mods to load Vietnam.

Persia retains its private roster, Divans, landmarks, current visuals, owning
resource overlays and lifecycle. Korea retains its roster, Literature/foreign
research, transformations, Scholar/Seowon/landmark systems, barrage repairs and
information panel. The Korean native resource UI record remains scoped by the
new race; its actual in-game Literature display is a required retest.

## Editable and storage boundary

Keep only this civilization's current source/masters and needed native family.
Historical superseded unit trials, old complete releases, the combined Git
database, whole immutable packs and broad cook/readback caches are not copied.
Direct Blender dependencies are included individually and deduplicated by hash.
Opaque native state/material/animation owners are conservatively retained where
text-only reachability cannot justify omission. Do not strip them based on names.

Native default/campaign graphs, full roster loading, PBG/locale closure, native
CRC/SHA1 and complete readback are package gates. Import, gameplay, save/load,
AI, multiplayer and live performance are separate. The local first version is
a test candidate, not a claim of native acceptance.
