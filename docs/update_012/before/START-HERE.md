# Vietnam — Garrison test candidate

Import the single Vietnam-Garrison-0.1.1.zip through Garrison 0.1.9 or newer,
enable Vietnam, and launch a fresh match with native Standard, Tuning Pack None,
and Vietnam chosen directly in the civilization dropdown.

Use a human player, standard starting army/resources and Dark Age. Start with a
stock opponent and keep the old combined pack disabled. This standalone candidate
needs native import and gameplay testing. Custom AI, Nomad, later-age starts,
save/load, multiplayer and performance are not yet qualified. Korean custom
models remain deferred.

Players need only this ZIP. Developers use the complete source repository.
